Description
This is a website I made for an artist named Ruben. On this website, he promotes himself en sells his artworks. The website has 2 different pages, a homepage and a checkout page.
Because of the artist’s personal preferences, I did not use an online payment provider like Mollie for the payment processing. Instead I sent an automatic email to the client with a link to pay for the selected product.

Here is some technical information about the website
-Languages frontend: html, css, javascript (no framework)
-Language backend: Python
-Host (web service): Render

I did not use A.I to write code for this website. I did use A.I however to explain how to implement some technical features (like an automated email) and for debugging.

Please note that the backend only works on Render https://rubenart-website.onrender.com
